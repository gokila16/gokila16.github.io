TinyRobotLM: a language model small enough to live on the robot

A 3.2M-parameter transformer we trained from scratch that turns plain-English commands into robot programs, running fully offline on a 2019 Jetson Nano right next to a YOLO detector. No cloud calls, no API bill, and latency you barely notice. Built in 24 hours, and it won Best Overall.

FITTING ON A 2019 JETSON

Small model, clean data. We built a 41,000-example dataset with no leakage between training and test phrasings, so the 93.8% reflects commands the model had never seen.

No framework needed. The Nano is stuck on JetPack 4.5 and Python 3.6, so I rewrote transformer inference in pure NumPy with KV caching. It matches PyTorch within 2×10⁻⁶.

Two models, one board. Language inference and YOLO perception run side by side on the Nano, replacing a camera-to-cloud loop that sent one frame every five seconds.

KEEPING IT SAFE

Only valid programs. Constrained decoding and a grammar validator mean the model can only produce commands the robot knows how to run.

Hard limits. Every motion is capped at 15 seconds, the controller works with the motor watchdog, and an emergency stop is always one click away.

No jumping at shadows. A target has to show up in two frames in a row before the robot acts on it.
