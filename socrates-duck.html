Socrates' Duck: a debugging coach that won't hand you the answer

A VS Code extension that walks developers through their bugs with step-by-step hints instead of writing the fix for them. It's built to teach, so the hardest part was making sure the hints never quietly give the answer away.

KEEPING IT SAFE

Two-layer leak guard. Code-parsing rules catch complete solutions, and an LLM reviewer checks each hint. If the reviewer fails, the system falls back to a safe hint rather than risk a leak.

Prompt-injection defense. All user code is wrapped in random per-request markers, so text inside a file can’t pose as instructions.

Stays on your machine. The backend only listens on localhost, so a malicious repository can’t send your code anywhere.

ENGINEERING CHOICES

Predictable by design. Hint difficulty lives in deterministic code, not the model, so behavior is testable.

Any model provider. A provider-agnostic layer over LiteLLM supports OpenAI and Anthropic, with typed errors, validated output, and per-step reasoning effort.

Tested without API costs. pytest and Vitest suites run on fake LLM providers, and GitHub Actions checks types (mypy, tsc) on every pull request.
